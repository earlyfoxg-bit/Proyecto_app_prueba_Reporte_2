# Proyecto_app_prueba_Reporte_2

App web instalable (PWA) para crear y guardar reportes con título, descripción y prioridad.

## Archivos

- `index.html`: interfaz y lógica de la app.
- `manifest.json`: configuración de la PWA (nombre, colores, íconos, modo standalone).
- `sw.js`: service worker.
- `icon-192.png` / `icon-512.png`: íconos de la app.

## Uso

Abre `index.html` en el navegador o instálala en el teléfono desde el menú del navegador ("Agregar a pantalla de inicio").
